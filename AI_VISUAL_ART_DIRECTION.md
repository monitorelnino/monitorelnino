# CONSTITUIÇÃO VISUAL E DIREÇÃO DE ARTE

Estas regras governam a estética, direção de arte, composição, visualização de dados e experiência visual deste projeto.

O objetivo NÃO é apenas tornar o site organizado ou agradável.

O objetivo é construir uma identidade visual própria, reconhecível e coerente com a narrativa do projeto.

O site deve parecer concebido especificamente para esta investigação.

Ele não deve parecer um template de dashboard, um portal governamental genérico, um relatório de consultoria ou um site institucional produzido a partir de componentes padrão.

## 1. PRINCÍPIO CENTRAL

Rigor científico e riqueza visual não são opostos.

A seriedade do projeto deve vir de:

- qualidade dos dados;
- transparência metodológica;
- precisão;
- clareza;
- hierarquia da informação.

Ela NÃO precisa ser comunicada através de:

- monotonia;
- excesso de branco;
- cinza institucional;
- layouts burocráticos;
- repetição de cards;
- gráficos visualmente indiferenciados.

O site deve ter personalidade.

## 2. CONCEITO VISUAL

Trate o site como uma combinação entre: publicação editorial contemporânea + observatório de dados + narrativa visual digital.

A experiência deve transmitir: investigação; movimento; território; clima; antecipação; observação; conexão entre escalas; complexidade organizada.

Evite transformar esses conceitos em ilustrações literais. Não use automaticamente: planeta Terra; termômetros; nuvens; folhas; gotas; ícones meteorológicos genéricos; símbolos ambientais clichês.

A identidade deve ser abstrata o suficiente para adquirir linguagem própria.

## 3. PERSONALIDADE

O projeto deve parecer: inteligente; contemporâneo; visualmente sofisticado; vivo; editorial; preciso; investigativo; inesperado em alguns momentos; elegante sem ser luxuoso; experimental sem comprometer leitura.

Ele NÃO deve parecer: corporativo; infantil; cartoon; excessivamente tecnológico; dashboard SaaS; portal governamental; apresentação PowerPoint; template de startup; interface clínica sem personalidade.

## 4. RITMO VISUAL

Não trate todas as informações com o mesmo peso. Construa ritmo.

Alterne deliberadamente entre: momentos densos e momentos de respiro; grandes visualizações e pequenos detalhes; visão nacional e detalhe local; dados quantitativos e contexto; composições amplas e blocos compactos.

Uma página longa não deve parecer uma pilha de módulos idênticos.

Evite a sequência repetitiva TÍTULO / TEXTO / GRÁFICO, repetida indefinidamente. Construa composição editorial.

## 5. ASSIMETRIA CONTROLADA

A grade deve garantir coerência, mas não produzir monotonia.

Use assimetria quando ela ajudar a criar: hierarquia; movimento; tensão visual; relação entre texto e dados.

Nem tudo precisa ficar centralizado. Nem toda visualização precisa ter a mesma largura. Nem toda seção precisa usar a mesma composição. A diversidade deve ocorrer dentro de um sistema coerente.

## 6. VISUALIZAÇÕES COMO PARTE DA COMPOSIÇÃO

Gráficos não devem parecer elementos incorporados posteriormente ao design. Eles são componentes centrais da direção de arte.

Quando apropriado: permita que ocupem grande parte da viewport; utilize dados como elemento compositivo; integre títulos e valores à visualização; use espaço negativo como parte da leitura; dê destaque visual a comparações importantes; permita exploração progressiva.

Evite colocar automaticamente cada gráfico dentro de um card.

**CARD NÃO É UNIDADE NARRATIVA.** Use cards somente quando a informação realmente possuir natureza modular.

## 7. DIFERENTES DADOS, DIFERENTES FORMAS

Não force todos os dados para o mesmo formato visual. Escolha a representação a partir da pergunta.

Considere: mapas; dot plots; barras; séries; pequenos múltiplos; matrizes; grids territoriais; timelines; diagramas; números destacados; comparação lado a lado; progressões espaciais; visualizações interativas.

Não crie variedade apenas por estética. Forma deve nascer da função.

## 8. HIERARQUIA VISUAL DOS DADOS

Nem todo número precisa competir pela atenção. Para cada seção, determine:

- **dado principal** — o que o leitor precisa perceber primeiro;
- **dado secundário** — o que contextualiza;
- **detalhe explorável** — o que pode ser descoberto através de interação ou leitura posterior.

A hierarquia visual deve refletir essa estrutura.

## 9. COR COMO SISTEMA SEMÂNTICO

A paleta não é decoração. Cada cor deve possuir função.

Defina pelo menos: cor estrutural; fundo; texto principal; texto secundário; destaque; categorias; estados; ausência de dados; interação; alerta quando semanticamente necessário.

Não introduza uma nova cor apenas porque ela fica bonita naquela seção.

## 10. COR NÃO É JULGAMENTO

Não use automaticamente verde = bom e vermelho = ruim, a menos que a semântica realmente exija essa interpretação.

Uma escala de preparação ou presença/ausência deve seguir a metodologia do indicador. Não introduza julgamento visual que os dados não sustentam.

## 11. PALETA EXPRESSIVA

A paleta pode ser intensa. Não é necessário trabalhar apenas com tons pastéis ou institucionais. Procure profundidade cromática.

Prefira cores que tenham: saturação controlada; contraste; profundidade; presença.

Quando adequado, explore uma sensação de cor mineral ou de pedra preciosa: verdes profundos; azuis densos; turquesas; ametistas; magentas escuros; âmbar; cobre; tons minerais.

O resultado não deve parecer neon gratuito. A intensidade deve ser sofisticada.

## 12. LUZ E PROFUNDIDADE

Quando compatível com o sistema visual, a cor pode ter pequenas variações de luminosidade, transparência ou profundidade.

Evite: gradientes genéricos de startup; glassmorphism gratuito; brilho plástico; efeitos 3D decorativos.

Profundidade deve ser usada com discrição.

## 13. TIPOGRAFIA

A tipografia deve contribuir para a identidade do projeto. Não dependa apenas da hierarquia padrão 48 / 32 / 24 / 16 px. Crie uma escala tipográfica coerente e responsiva.

Diferencie claramente: títulos narrativos; títulos de seção; títulos de visualização; corpo; legendas; notas; fontes; números destacados.

Grandes números podem funcionar como elementos gráficos. A tipografia pode participar da composição.

## 14. NÃO USAR TAMANHO COMO ÚNICO RECURSO

Hierarquia também pode ser construída através de: peso; largura; posição; espaço; contraste; ritmo; alinhamento; relação com outros elementos.

Evite simplesmente aumentar tudo que precisa de destaque.

## 15. LINGUAGEM GRÁFICA

Crie um vocabulário gráfico próprio para o projeto. Pode utilizar, quando coerente: linhas; traços; contornos; superfícies; campos de cor; formas orgânicas; marcas gestuais; texturas discretas; elementos inspirados em fluxo, deslocamento ou circulação.

Esses elementos devem aparecer de maneira consistente ao longo do site. Não adicione decoração aleatória.

## 16. ELEMENTOS ORGÂNICOS

Quando houver elementos abstratos ou gestuais, evite aparência vetorial excessivamente perfeita. É permitido utilizar características discretamente orgânicas: irregularidade; textura; variação de espessura; término semelhante a pincel; sobreposição; transparência.

Isso pode criar contraste entre a precisão dos dados e uma linguagem visual mais humana. Nunca prejudique a leitura.

## 17. MICROINTERAÇÕES

Interações devem ajudar o usuário a compreender. Considere: destaque ao hover; transições suaves; mudança de escala territorial; revelação progressiva; filtros; tooltips; comparação; seleção de estado ou município; continuidade visual entre diferentes escalas.

Evite animação ornamental. Movimento deve comunicar mudança, relação ou progressão.

## 18. SCROLL COMO NARRATIVA

Quando apropriado, use a rolagem como mecanismo de progressão narrativa. Uma visualização pode começar no Brasil, destacar estados, chegar aos municípios e revelar novas camadas progressivamente.

Não utilize scrollytelling simplesmente como efeito. Use apenas quando ele tornar a história mais inteligível.

## 19. EVITAR A ESTÉTICA DE TEMPLATE

Procure especificamente e elimine dependência excessiva de: cards idênticos; border-radius uniforme em tudo; sombras padronizadas; ícones genéricos; hero padrão; grade repetitiva de três colunas; gráfico dentro de caixa branca; título centralizado + subtítulo + botão; gradiente decorativo; seções alternando branco e cinza sem função.

Esses padrões não são proibidos individualmente. O problema é utilizá-los como arquitetura automática.

## 20. PERSONALIDADE NÃO SIGNIFICA CAOS

A criatividade deve operar dentro de um sistema. Defina: grid; escala de espaçamento; escala tipográfica; tokens de cor; raios; regras de contraste; largura máxima; comportamento responsivo; famílias de composição.

Depois permita variações dentro desse sistema.

## 21. FAMÍLIAS DE COMPOSIÇÃO

Em vez de usar um único layout, desenvolva algumas famílias coerentes:

- **NARRATIVA** — texto e evidência principal.
- **IMERSIVA** — uma visualização ocupa grande parte da tela.
- **COMPARATIVA** — dois ou mais territórios ou indicadores em relação direta.
- **EXPLORATÓRIA** — mapa ou gráfico interativo com controles.
- **SÍNTESE** — poucos números ou indicadores de alta hierarquia.
- **AÇÃO** — informação territorial seguida de caminhos concretos de ação.

Use a família adequada à função narrativa.

## 22. COERÊNCIA ENTRE NARRATIVA E DESIGN

A composição deve responder ao estágio da história:

contexto nacional → composição ampla; diferenças estaduais → comparação; variação territorial → mapa; município do usuário → foco localizado; síntese → redução de complexidade; ação → interface clara e operacional.

Não escolha layout independentemente da narrativa.

## 23. ACESSIBILIDADE

Criatividade visual nunca pode comprometer: contraste; legibilidade; daltonismo; navegação por teclado; tamanho mínimo de texto; compreensão sem interação; responsividade; leitura em dispositivos pequenos.

Não dependa exclusivamente de cor para comunicar categorias.

## 24. MOBILE NÃO É UMA VERSÃO DIMINUÍDA DO DESKTOP

Recomponha. No mobile: priorize; reduza simultaneidade; reorganize gráficos; adapte legendas; substitua comparações horizontais quando necessário; preserve hierarquia.

Não simplesmente comprima o layout desktop.

## 25. PROCESSO DE REDESIGN

Antes de alterar componentes individualmente:

1. observe o site inteiro;
2. identifique padrões visuais repetitivos;
3. identifique onde aparece aparência de template;
4. identifique ausência de ritmo;
5. identifique inconsistências;
6. reconstrua a direção visual global;
7. crie tokens e princípios;
8. escolha famílias de composição;
9. redesenhe primeiro páginas representativas;
10. valide o sistema;
11. só depois propague.

Não faça maquiagem componente por componente.

## 26. TESTE DA PERSONALIDADE

Depois do redesign, faça estas perguntas:

- Se o logotipo fosse removido, o projeto ainda teria identidade?
- Este site poderia pertencer a qualquer startup?
- Os gráficos parecem pertencer ao mesmo universo visual?
- Existe ritmo entre as seções?
- Há momentos visualmente memoráveis?
- A estética ajuda a entender a narrativa?
- Existe alguma criatividade além de cores e sombras?
- O projeto parece concebido especificamente para este conteúdo?

Se as respostas indicarem genericidade, o trabalho não terminou.

## 27. REGRA FINAL

Não "embelezar componentes". Construa uma DIREÇÃO DE ARTE.

Não pergunte apenas: "Como deixo este bloco mais bonito?"

Pergunte: "Que experiência visual melhor expressa esta parte da história?"

A estética deve emergir da narrativa, dos dados e da identidade do projeto.
